AHRE Project System Architecture

Step 1: Synthetic CERT Ingestion Engine
Parses enterprise CSV logs (`logon.csv`, `device.csv`, `file.csv`) aggregating daily user behavioral vectors.
Step 2: Feature Engineering Matrix
Computes 6 key behavioral features: `off_hours_logins`, `failed_logins`, `usb_connect_count`, `file_copy_count`, `total_file_access`, `total_logons`.
Step 3: IsolationForest ML Model (Unsupervised)
Calculates anomaly decision scores based on path length isolation across 100 decision trees (`contamination=0.08`).
Step 4: Dynamic Risk Normalization (0-100)
Maps raw IsolationForest anomaly scores to an intuitive 0–100 cybersecurity threat scale, categorized into LOW, MEDIUM, HIGH, and CRITICAL.
Step 5: Explainable AI (XAI) Attribution
Converts mathematical feature distance into human-understandable security root-cause explanations for SOC Analysts.
